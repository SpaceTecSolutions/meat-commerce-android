# Meat Station website redesign prototype

Static responsive storefront concept inspired by the Instagram Reel shared by the user. The design uses its cinematic, dark food-editorial direction—gold accents, oversized serif product typography, dramatic photography, and image-led storytelling—adapted to Meat Station's actual meat catalog and branding.

## Preview

Run `python -m http.server 4173` from this directory and open `http://localhost:4173`.

The featured-cut carousel, in-page navigation, responsive menu, hover tilt, and scroll reveals are front-end prototype interactions. Store and collection links continue to open the current DotPe storefront; checkout, prices, account, and cart are not reimplemented.

## Publishing note

The live domain is served by DotPe and this repository does not contain its storefront source. This prototype is not connected to DotPe or deployed to `meatstation.org`. Publishing it requires a migration plan and access to the site's domain/storefront settings.
